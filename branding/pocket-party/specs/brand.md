# Brand construction

Name: Pocket Party. Playful, crisp, social. Default dark. Use lime only for action, brand and a few selection cues; lilac gives the brand its secondary personality. Secondary body text is neutral, not lilac.

Wordmark: Space Grotesk 700, lowercase boredgames.io, tightly spaced at approximately -0.045em. In dark mode bored and .io off-white, games lime. In light mode all text ink, optionally games #405D17; do not use pale lime text on white. Preserve .io at full baseline. Header 24px font on mobile, 30px desktop. Compact logo needs at least 160px width; minimum height 24px. Clear space half wordmark cap-height. One-colour usage all one ink. SVGs are starting live-text constructions, not exact outline reproductions.

App icon: 64x64 coordinate system, lime square radius16, two dark eye strokes at x20 and44, dark open smile. Render monochrome silhouette on contrasting surface when needed. 16/32px use simplified smile, not tiny phone details.

Mascots: tall portrait phones ~112x209 body, radius23, lilac bored and lime happy, no inset screen/glass lines; speaker slot, simple faces, small arms/feet. Solid dark outlines 6px at190px viewBox width. In UI max 70px high mobile, 112px desktop; pair angled -8/+8deg. Artwork may sit outside the comparison board frame but must not intrude into app controls. Decorative images have empty alt. One original pose per character supplied; additional celebration pose can be CSS transform rather than new artwork.

Icons: 24x24 viewBox, 1.8px line, rounded joins, visible at20–24px. Game accents are surface/icon decorations with neutral labels. App icon and selected state need not share game accent. Use text labels and selected checkmark, never colour alone.

Typography: H1 32 mobile/48 desktop, H2 22/26, body15/16, label 12. Space Grotesk700 headings, Inter400–700 body, IBM Plex Mono600 code. No gradients/glows, no UI drop shadows except overlays. Font licensing/source acquisition remains an implementation step; no font binaries bundled.
