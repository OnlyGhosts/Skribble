# boredgames.io logo files

Outlined vector logos: every letter is a path, so they render identically everywhere and need no font.

- boredgames-wordmark.svg — fill: currentColor (use inline, colour via CSS)
- boredgames-wordmark-offwhite.svg — #F1F0E8 on dark backgrounds
- boredgames-wordmark-ink.svg — #141514 on light backgrounds
- boredgames-wordmark-lilac-io.svg — off-white with a lilac .io (headline emphasis variant)
- boredgames-inverse.svg — ink wordmark on a lime rounded tile (the "inverse logo")
- boredgames-monogram.svg — "bg." tile for avatars and small spaces
- *-alt-outfit.svg — the same set in Outfit Black, kept as an alternate cut
- favicon.svg — the smile tile from the brand pack (unchanged)

Lettering: "boredgames" set in Poppins Black (900), ".io" in Poppins Regular (400), tracking -0.045em,
converted to outlines with fontTools + HarfBuzz. Poppins and Outfit are released under the SIL Open
Font License, which permits outlining and redistribution of the resulting artwork. The reference
mood board was generated with an unidentified "custom geometric sans"; this is the closest open
match, not a trace of it.
