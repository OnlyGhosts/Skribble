# Pocket Party implementation pack

Copy this folder into the existing boredgames repository, then give Claude Code CLAUDE_CODE_PROMPT.md. Open preview/index.html in a browser to review the deterministic component and screen references; no installation is required. Use the theme switch at the top to see both themes.

Priority: approved-pocket-party.png for visual direction; specifications and tokens for exact behavior and dimensions; original app screenshots for existing content. Do not use any previous rebrand pack as the authority.

Included: full dark/light token contract matching the brief, CSS variables, brand and component specifications, motion and copy, all seven game treatments, original app reference sheets, the approved mockup, editable SVG mascot/icon/wordmark assets, raster icons, and an offline preview for Home, name, Lobby, Podium and seven games.

Limitations: generated mockup lettering is not an identifiable exact font. Space Grotesk + Inter are the chosen implementation faces. SVG wordmarks have live text and need those fonts installed to match the intended metrics; they are not exact traced outlines. Mascots are editable reinterpretations. The offline preview uses system-font fallbacks unless the chosen fonts are installed; it contains illustrative static data and is not a live multiplayer app. Original imagery is a visual reference, not a flattened app background. The written spec fixes the stray face lines and unnecessary game-state controls in the generated mockup.
