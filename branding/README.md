# Brand

- [`pocket-party/`](pocket-party/START_HERE.md): the Pocket Party pack, the brand and UI authority (approved board, specs, tokens, icons, mascots, app icon, offline preview).
- [`logo/`](logo/): the boredgames.io wordmark outlined in Space Grotesk 700 (dark, light, ink, off-white, one-colour and two-tone `currentColor` versions).
- [`archive/first-rebrand/`](archive/first-rebrand/README.md): the previous pack and logo set, superseded.

The owner's decisions override the pack where they differ: content modes are Family and Unhinged (18+) only, there is no max-players setting, the drawing game is called Scribble (internal id `skribble`), sound effects are wanted, Blackjack, Poker and Battleships get new flows, and no user-facing text uses em dashes or taglines.
